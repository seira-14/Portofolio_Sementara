# Website Portofolio 

## Deskripsi
Website Portofolio merupakan website berbasis web yang dirancang untuk menampilkan profil, pengalaman, keterampilan, pendidikan, serta berbagai project yang telah dikerjakan. Website ini dibuat sebagai media personal branding sehingga memudahkan recruiter, dosen, maupun klien untuk mengenal profil dan melihat hasil karya secara profesional.

Website dikembangkan menggunakan HTML, CSS, JavaScript, dan PHP, dengan tampilan yang modern, responsif, serta mudah diakses pada berbagai perangkat.

## Bahasa Pemrograman
- PHP
- HTML
- CSS
- JavaScript
- MySQL

## Framework
- Bootstrap 5

## Fitur
- Hero Section sebagai halaman utama.
- Informasi profil singkat.
- Halaman About Me.
- Daftar keterampilan (Skills).
- Riwayat pendidikan.
- Pengalaman organisasi dan kepanitiaan.
- Showcase project atau portofolio.
- Form kontak.
- Integrasi database menggunakan MySQL.
- Responsive Design.
- Modern User Interface (UI).

## Cara Menjalankan

1. Simpan folder project ke dalam direktori:

```text
C:\xampp\htdocs\
```

2. Jalankan / Start Apache dan MySQL melalui XAMPP Control Panel.

3. Buat database sesuai file SQL yang tersedia pada folder `backend`.

4. Import file `database.sql` menggunakan phpMyAdmin.

5. Buka browser, kemudian akses:

```text
http://localhost/website_portofolio/
```

## Tujuan Project

Project ini dibuat sebagai media personal branding untuk menampilkan profil, keterampilan, pengalaman, dan hasil karya secara profesional. Website ini juga bertujuan memudahkan recruiter maupun klien dalam mengenal kemampuan pengembang melalui tampilan yang informatif, modern, dan responsif.
